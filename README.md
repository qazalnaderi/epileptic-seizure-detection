# Epileptic Seizure Recognition Using Supervised Learning and EEG Clustering

A machine learning project for binary seizure recognition from EEG signal segments, combining supervised classification, PCA-based analysis, and exploratory K-Means clustering.

> This project is intended for educational and portfolio purposes only. It is not a medical diagnostic system.

## Overview

The dataset contains 11,500 fixed-length EEG signal segments. Each sample is represented by 178 sequential EEG measurements and an original target label with five classes.

For this project, the original task is converted into binary classification:

- `1` → Seizure
- `0` → Non-Seizure

Original class `1` is treated as seizure activity, while original classes `2`, `3`, `4`, and `5` are grouped as non-seizure conditions.

The notebook includes:

- Dataset loading and inspection
- Data quality and outlier analysis
- Exploratory data analysis
- Binary target construction
- Stratified train/test splitting
- PCA-based dimensionality reduction
- Comparison of six supervised learning configurations
- Confusion-matrix and ROC-curve analysis
- Exploratory K-Means clustering
- Cluster-count evaluation with internal metrics
- Cluster composition and PCA visualization
- EEG segment prediction helper
- Model persistence with `joblib`

## Methodology

### Target Transformation

The original five-class target is transformed as follows:

```text
Original class 1       → Seizure
Original classes 2–5   → Non-Seizure
```

The identifier and target columns are excluded from the model input.

### Data Split

The dataset is divided into:

| Split | Samples | Non-Seizure | Seizure |
|---|---:|---:|---:|
| Training set | 9,200 | 80% | 20% |
| Test set | 2,300 | 80% | 20% |

Stratification is performed using the original five-class labels so that the source EEG groups remain represented in both subsets.

### Supervised Models

The following configurations are compared:

- Logistic Regression
- Random Forest
- K-Nearest Neighbors
- Support Vector Machine
- PCA + Logistic Regression
- PCA + Support Vector Machine

Model comparison includes:

- Accuracy
- Balanced accuracy
- Seizure precision
- Seizure recall
- Seizure F1-score
- ROC-AUC

### Unsupervised Clustering

The clustering pipeline is fitted without using target labels:

1. Standardization with `StandardScaler`
2. PCA retaining 95% of the training variance
3. K-Means clustering
4. Evaluation of candidate cluster counts from `k=2` to `k=8`

The following internal metrics are calculated:

- Inertia
- Silhouette score
- Davies-Bouldin index
- Calinski-Harabasz score

Target labels are used only after clustering for post-hoc interpretation.

## Results

### Supervised Classification

| Model | Accuracy | Balanced Accuracy | Seizure Precision | Seizure Recall | Seizure F1 | ROC-AUC |
|---|---:|---:|---:|---:|---:|---:|
| **SVM** | **0.9761** | **0.9745** | 0.9141 | **0.9717** | **0.9420** | 0.9959 |
| PCA + SVM | 0.9757 | 0.9742 | 0.9122 | **0.9717** | 0.9411 | 0.9957 |
| Random Forest | 0.9743 | 0.9668 | 0.9203 | 0.9543 | 0.9370 | **0.9964** |
| KNN | 0.9278 | 0.8204 | **0.9966** | 0.6413 | 0.7804 | 0.9209 |
| Logistic Regression | 0.6878 | 0.6027 | 0.3109 | 0.4609 | 0.3713 | 0.5343 |
| PCA + Logistic Regression | 0.6017 | 0.5457 | 0.2385 | 0.4522 | 0.3123 | 0.5074 |

### Selected Supervised Model

SVM was selected as the final supervised model because it achieved the strongest overall balance of balanced accuracy, seizure recall, and seizure F1-score.

SVM confusion matrix:

| | Predicted Non-Seizure | Predicted Seizure |
|---|---:|---:|
| Actual Non-Seizure | 1,798 | 42 |
| Actual Seizure | 13 | 447 |

Summary:

- Correct predictions: 2,245 of 2,300
- Total errors: 55
- Missed seizure segments: 13
- False seizure alarms: 42
- Seizure recall: approximately 97.17%
- Seizure F1-score: approximately 94.20%

Random Forest achieved the highest ROC-AUC, but SVM produced the best balanced accuracy and seizure F1-score.

### Clustering Results

The highest silhouette score among the evaluated candidates was obtained at `k=8`.

| Metric | Result |
|---|---:|
| Evaluated range | `k=2` to `k=8` |
| Selected candidate by silhouette | `k=8` |
| Silhouette score | 0.0869 |
| Davies-Bouldin index | 3.2314 |
| Calinski-Harabasz score | 184.0055 |
| Inertia | 1,370,054 |

The selected value should not be described as a confirmed optimal number of clusters. It was only the strongest candidate within the tested range.

The silhouette score is low, the elbow curve has no clear breakpoint, and the two-dimensional PCA visualization shows substantial overlap between clusters. Therefore, the current representation does not provide evidence of strongly separated natural EEG groups.

Cluster identifiers are arbitrary and must not be interpreted directly as seizure or non-seizure classes.

## Main Findings

- SVM produced the strongest overall supervised classification result.
- PCA preserved SVM performance but did not improve it.
- Random Forest achieved the highest ROC-AUC but slightly lower seizure recall and F1-score than SVM.
- KNN produced very high seizure precision but missed many seizure segments.
- Logistic Regression performed close to random ranking based on ROC-AUC.
- K-Means detected highly overlapping groups, so its output is exploratory rather than diagnostic.
- Supervised class separation was substantially stronger than the unsupervised cluster structure found in the current feature space.

## Limitations

- Each observation is a fixed-length EEG segment, not a complete patient-level recording.
- The current evaluation is dataset-specific and does not establish clinical generalization.
- The clustering quality is weak and must not be interpreted as clinical grouping.
- The tested clustering range ends at `k=8`, where the silhouette score is still increasing.
- Additional cluster counts and stability analysis should be evaluated.
- A dedicated validation set should be used for model selection and threshold tuning.
- The final test set should be reserved for a single unbiased evaluation.
- External validation on independent EEG datasets is required before making broader performance claims.

## Possible Improvements

- Introduce separate training, validation, and test subsets
- Perform cross-validation on the training data
- Tune model hyperparameters with `GridSearchCV` or `RandomizedSearchCV`
- Evaluate clustering stability across random seeds and bootstrap samples
- Test a wider range of cluster counts
- Compare K-Means with Gaussian Mixture Models, DBSCAN, and hierarchical clustering
- Engineer frequency-domain and statistical EEG features
- Add explainability analysis
- Evaluate on independent EEG datasets
- Add a separate inference script or lightweight application

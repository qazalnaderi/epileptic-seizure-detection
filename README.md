# Epileptic Seizure Detection with Machine Learning

A machine learning project for binary epileptic seizure detection using EEG signal features.

This notebook compares multiple classical machine learning models and selects the best model based on seizure recall, ROC-AUC, and F1-score. Since missing seizure cases can be critical, the model selection strategy gives priority to seizure recall.

## Overview

The dataset contains EEG signal features and an original target label with five classes.
In this project, the task is converted into a binary classification problem:

* `1` → Seizure
* `0` → Non-Seizure

The notebook includes:

* Dataset loading and inspection
* Data quality checks
* Outlier analysis
* Exploratory data analysis
* Binary target creation
* Train/test split with stratification
* PCA analysis
* Model comparison
* Confusion matrix visualization
* ROC curve visualization
* Threshold tuning
* Patient condition prediction helper
* Final model saving with `joblib`

## Dataset

The notebook expects the dataset file to be named:

```text
Epileptic Seizure Recognition.csv
```

Place this file in the same directory as the notebook before running it.

Common dataset source:

```text
https://www.kaggle.com/datasets/harunshimanto/epileptic-seizure-recognition
```

The dataset file should contain:

* EEG feature columns named like `X1`, `X2`, ..., `X178`
* a target column named `y`
* an identifier column named `Unnamed`

In this project, class `1` is treated as seizure activity, while classes `2`, `3`, `4`, and `5` are grouped as non-seizure conditions.

## Methodology

The original target column contains five classes.
For binary seizure detection, the target is transformed as follows:

```text
Original class 1       -> Seizure
Original classes 2–5   -> Non-Seizure
```

The final feature matrix uses the EEG signal columns only.
The identifier column and target columns are excluded from the model input.

The data is split into:

```text
80% training
20% testing
```

Stratification is used to preserve the original class distribution during splitting.

## Models Compared

The notebook compares the following models:

* Logistic Regression
* Random Forest
* K-Nearest Neighbors
* Support Vector Machine
* PCA + Logistic Regression
* PCA + Support Vector Machine

PCA is also used to analyze dimensionality reduction. In the notebook, 39 PCA components were enough to preserve at least 95% of the variance.

## Threshold Tuning

Because seizure detection is a healthcare-related classification task, reducing missed seizure cases is important.
The notebook performs threshold tuning using precision-recall analysis.

Selected threshold:

```text
0.3557
```

After threshold tuning:

| Metric            |  Value |
| ----------------- | -----: |
| Accuracy          | 0.9752 |
| Seizure Precision | 0.9242 |
| Seizure Recall    | 0.9543 |
| Seizure F1-score  | 0.9390 |

## Model Saving

The final selected model is saved using `joblib`:

```text
seizure_detection_model.joblib
```

The saved artifact includes:

* trained model
* feature column order
* label mapping
* selected model name

This helps ensure that future predictions use the same feature order as training.
